# **Push_Swap**

## **Description**
**Push_Swap** est un projet d'algorithme de la formation 42. Son objectif est de trier une pile d'entiers en utilisant un ensemble limité d'instructions et deux piles (`stack_a` et `stack_b`). Le défi consiste à écrire un programme en C qui trie la pile avec le moins d'opérations possible.

### **Objectifs**
- Implémenter un algorithme de tri efficace pour trier une liste d'entiers.
- Utiliser uniquement les opérations autorisées : `sa`, `sb`, `ss`, `pa`, `pb`, `ra`, `rb`, `rr`, `rra`, `rrb`, `rrr`.
- Optimiser le nombre d'opérations pour obtenir la meilleure note possible.
